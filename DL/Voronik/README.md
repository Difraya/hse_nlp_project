# Языковая модель для генерации текстов в стиле авторов

## Описание проекта  
Этот проект реализует **fine-tuning** языковой модели **GPT-2 large** для генерации текстов в стиле конкретных авторов. Для указания стиля используются специальные токены вида `[AUTHOR_Имя]`. Реализованы:  
- Кастомные callback-функции для логирования метрик.  
- Ранняя остановка при переобучении.  
- Поддержка генерации текстов с фильтрацией по авторам.

## Подготовка данных  
### Формат данных  
- **Формат файла**: `.parquet`  
- **Колонки**:  
  - `author` — имя автора (например, `Fyodor_Dostoyevsky`).  
  - `text` — текст произведения.  
Для обучения модели использован специально подготовленный датасет limited.pq в котором отобраны 33 автора из 100, а все тексты книг разбиты на фрагменты по 512 токенов, для каждого автора датасет содержит по 150 случайно выбранных таких фрагментов. Для обучения выбирается 33 случайных фрагмента для каждого автора.


### Этапы обработки  
1. **Добавление специальных токенов**:  
   Каждый текст преобразуется в формат `[AUTHOR_Имя] Текст произведения`.  
2. **Разбиение на train/validation**:  
   90% данных используется для обучения, 10% — для валидации.  
3. **Токенизация**:  
   Применяется токенизатор GPT-2 с добавлением специальных токенов для авторов.

## Архитектура модели  
- **Базовая модель**: `gpt2-large` (774М параметров).  
- **Модификации**:  
  - Добавлены специальные токены `[AUTHOR_Имя]` для указания стиля.  
- **Оптимизация**:  
  - FP16 для снижения потребления памяти.  
  - Градиентный чекпоинтинг для ускорения обучения.

## Обучение модели  
### Гиперпараметры  
| Параметр                | Значение          |
|-------------------------|-------------------|
| Learning rate           | 2e-5              |
| Batch size              | 1 (с накоплением 8)|
| Эпохи                   | 10                |
| Ранняя остановка        | 5 эпох без улучшений |
| Оптимизатор             | AdamW             |
| Валидация               | Каждые 50 шагов   |

### Логирование  
- Используются кастомные callback-функции для отслеживания loss и learning rate.

## Использование модели  
### Генерация текстов  
Функция `generate_text(author, prompt)` позволяет генерировать тексты в стиле указанного автора. Параметры:  
- `temperature=0.7` — контролирует случайность генерации.  
- `top_k=50`, `top_p=0.92` — фильтруют нерелевантные токены.  
- `repetition_penalty=1.2` — снижает повторения.

---

## Оценка качества генерации текстов в стиле авторов

### Описание  
Этот проект реализует оценку качества генерации текстов в стиле автора с использованием метрик **BERTScore** и **Perplexity**.  
- **BERTScore**: измеряет семантическую близость сгенерированного текста к эталонному.  
- **Perplexity**: оценивает уверенность модели в предсказаниях (чем ниже значение, тем лучше).

## Развертывание  
### Сохранение модели  
После обучения модель сохраняется в директорию `./author_style_gpt2`:  
```bash
model.save_pretrained('./author_style_gpt2')
tokenizer.save_pretrained('./author_style_gpt2')
```

### Интеграция  
Для использования модели в других проектах:  
```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer

model = GPT2LMHeadModel.from_pretrained('./author_style_gpt2').to(device)
tokenizer = GPT2Tokenizer.from_pretrained('./author_style_gpt2')
```
